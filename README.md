## Repository Structure

The repository is organized according to the required project guidelines:

```
/
├── proposal/         # Approved research proposal and design revisions
├── instruments/      # Data collection instruments (questionnaires, interview guides, protocols)
├── pilot-study/      # Pilot study documentation, feedback, and revisions
├── data/             # Cleaned and anonymized datasets
├── analysis/         # Analysis scripts, notebooks (Python/R/Excel/etc.), and output figures
├── report/           # Final research report drafts, source files, and final PDF
├── presentation/     # Presentation slides (PowerPoint/PDF)
├── meeting-notes/    # Minutes and action items from group meetings
├── references/       # Literature references, bibtex entries, and citation materials
└── README.md         # Project documentation and reproduction instructions
```

## Instructions for Reproducing Analysis
1. Clone the repository:
   ```bash
   git clone <repo-url>
   cd CloudComputing_RTW_Project
   ```
2. Navigate to the `analysis/` folder:
   ```bash
   cd analysis
   ```
3. Follow the specific instructions or run analysis scripts documented within the `analysis/` directory.
